DELIVERABLE 03 // PACKET-LEVEL ROOT CAUSE ANALYSIS (RCA)

Network Incident & Packet Analysis Case Study (Wireshark)

Status: Resolved & Documented
Symptom Reported

Intermittent 8–12s ERP/Web delays & failed internal host lookups

Primary Wireshark Filters

dns.flags.rcode != 0
tcp.analysis.retransmission

MTTR / Outcome

Latency cut from 9.4s to 140ms; 0% packet loss post-fix

1. Packet Capture Findings

  • Filtering with dns.flags.rcode != 0 revealed repeated DNS RCODE 2 (Server Failure) and timeout retries on endpoints configured with a stale secondary ISP DNS ahead of the internal AD DNS server.
  • Filtering with tcp.analysis.retransmission || tcp.analysis.duplicate_ack isolated a duplex mismatch on an access-layer switch uplink causing 11.4% TCP segment retransmissions during peak HTTP file uploads.

2. Corrective & Preventive Remediation

  • Updated DHCP Option 006 across all VLAN scopes so internal Domain Controllers act as sole primary/secondary DNS resolvers, forwarding external queries upstream.
  • Hardcoded speed 1000 and duplex full across distribution-to-access uplinks and enabled SNMP interface error alerts.
